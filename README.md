# Ăn Gì Bé Ơi 💕 (Food Picker for Couples)

Ứng dụng web thông minh giúp các cặp đôi giải quyết câu hỏi muôn thuở: **"Hôm nay ăn gì bé ơi?"**

## 🌟 Tính năng nổi bật
- **Giải mã cơn thèm ✨:** Trắc nghiệm 3 câu hỏi siêu tốc tìm ra món ăn chân ái của nàng.
- **Vòng quay cứu nguy tức thì 🎡:** 
  - Vòng quay may mắn với hoạt ảnh mượt mà, pháo hoa ăn mừng và âm thanh sống động.
  - Hỗ trợ thêm/xóa món ăn trực tiếp, lọc theo chủ đề (Đồ nước, Đồ nướng/lẩu, Trà sữa/tráng miệng, Tự thêm).
  - Tích hợp bộ chọn biểu tượng (Emoji Picker) đa dạng 7 danh mục.
  - **Mini Floating Wheel Widget:** Widget vòng quay mini nổi ở góc màn hình có thể kéo thả di chuyển tự do.
- **Sổ tay nàng 📖:** 
  - Hồ sơ sở thích ăn uống (tỉ lệ đồ nước/khô, độ cay, công thức trà sữa ruột, danh sách cấm vận).
  - Hỗ trợ đổi Avatar từ biểu tượng có sẵn hoặc **tải ảnh trực tiếp từ thiết bị/máy tính**.
  - Quản lý danh sách Quán Ruột và Blacklist cấm vận linh hoạt.
- **Bản đồ radar cứu đói 🗺️:** Tìm kiếm và lưu lại quán tủ quanh khu vực.

## 🚀 Cách chạy ứng dụng
Mở trực tiếp tệp `index.html` bằng bất kỳ trình duyệt web hiện đại nào (Chrome, Edge, Safari, Firefox). Không cần cài đặt server hay backend.

## 🛠️ Công nghệ
- HTML5, CSS3, JavaScript (ES6+)
- Tailwind CSS (CDN)
- Google Material Symbols & Plus Jakarta Sans Font
